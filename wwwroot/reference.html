Эталон первого API · E01

В вашем проекте first-api маршрут GET /api/game читает состояние для прогноза. POST /api/expeditions/E01/transitions передаёт команду {"action":"launch"} для конкретного рейса.

ЛР01. Заинтересованные стороны

Эталон по донесению

Задание для сверки. Заполните пять строк карты по С1–С6. Для каждой оценки укажите, какое действие или ответственность подтверждает источник. Затем запишите два вопроса разным участникам о деталях, которых в донесении ещё нет. Укажите, какое решение изменит каждый ответ.

Ответы испытания

  1. Диспетчер. Редактор публикует условия, а диспетчер разрешает действие с подготовленным рейсом.
  2. Значение физического запаса у снабжения. Дефицит проверяется по фактическому запасу. Снабжение подтверждает эти данные.

Переход читается по одной строке: состояние слева от стрелки, проверка в предусловии, новое состояние или отказ в результате. При замене проверяют физический запас, потому что старый резерв освобождается в той же транзакции. При отказе не подтверждается ни одно изменение.

Ответы испытания

  1. prepared. Запуск уже списал ресурсы. Замена относится к существующему резерву.
  2. prepared. Отказ сохраняет исходную попытку и её резерв.
